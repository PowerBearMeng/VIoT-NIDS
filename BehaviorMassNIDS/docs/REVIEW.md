# 当前实现的审阅要点

## 方法口径

当前版本是固定正常测量器＋条件行为强度建模（CBIM，192秒GRU/8状态密度）＋原型距离。CBIM对应旧实现的Mass支路；名称体现行为归属、完整强度和历史条件预测，模型及既有分数保持一致。它不是早期HN图模型，也没有启用CL或多尺度分支。原型在全部正常Flow上学习，匿名发送节点只改变数量归属及历史。

完整25维输入采用`log1p＋Robust`，正常拟合的尺度设下限。原型距离在标准化32维表示空间计算，径向距离尺度不是Gaussian标准差。实际FPB不按邻居数量归一化；预测当前数量的网络只读取过去、行为和方向。

## 已有检测证据

参见`results/reference/fusion_capture_metrics.csv`、`fusion_macro_metrics.csv`及`fusion_pooled_metrics.csv`。主比较是同192秒历史、同五捕获，不据某一攻击切换融合策略。AP使用average precision；EER使用ROC线性交点，最近经验EER点另存诊断。

同一群体成员共享Mass分数，因此仍有正常成员被牵连。OS Scan攻击期间正常RTCP的44/550条超过正常训练P99；固定正常特征/参数、离线移除当前攻击数量后为0，单独移除过去仍为44。该实验使用标签只定位污染通路，不是可部署改进。两种移除也无法恢复攻击已改变的正常Flow形态。

## 整理后的代码边界

从原代码逐符号抽取测量网络、行为尺度、活动索引、历史密度、正常采样及指标公式；来源见`SOURCE_MAP.csv`。新增自包含模型bundle使用JSON尺度和`weights_only=True`状态字典，运行时不依赖原目录、joblib对象或旧报告模块。导出脚本只在转换时读取原工程。

新增正常训练入口保留正常遮蔽预训练与固定测量边界。GRU/MDN从新状态或明确的`initial_mass.pt`开始；不会因提供测量bundle而加载已训练检测器。测试不更新正常尺度、原型、状态参数或权重。

本轮没有执行新增训练入口的完整训练；已实际核对的是模型转换、冻结推理及指标。新训练代码的结果须在新实验中确认，不能视为已重训复现。

必要核对使用真实正常缓存和既有OS Scan完整缓存，核对标签人口、原始数量、行为分组、分数及冻结参数。记录在`results/reference/portability_checks.json`。未运行smoke test、未新训练、未用攻击表现调整实现或超参数。

K8正常原型距离/Mass原始分数最大差为0；OS Scan的融合分数最大差约`5.6e-16`，AUROC/AP/插值EER与原结果一致。K16正常原始分数也一致。匿名节点置换后的最大差约`4.0e-7`，在有限精度容差内；节点编号没有进入网络。

## 应继续研究的问题

1. **成员归因：** 同群体成员共享Mass。形态完全相同的正常与攻击成员仍可能同分。
2. **历史污染：** 冻结正常状态限制均值外推范围，但攻击历史仍能改变混合权重；不等于参照保护已完成。
3. **密度近似：** FPB有整数性、约束和相关性。对数变换后的对角Gaussian混合是连续近似，不能称精确计数概率。没有加入原空间Jacobian，当前NLL均在变换空间解释。
4. **融合：** Q50/Q95固定相加提供已观察的互补收益，但不能保证每场景或每个阈值改善。正常距离低分不会否决很大的群体Mass。
5. **评价：** 单种子、五捕获、正常尺度来自训练内数据。EER和高攻击占比下的AP不能代替独立正常漂移或部署误报评估。
6. **实时系统：** 代码进行完整捕获的离线因果评分，不是live服务。PCAP准备保留整份捕获的统计数组；Activity建立节点×秒×行为库。大规模、多节点捕获还需控制缓存内存、在线flush、峰值队列和延迟。

这些问题不通过换名或方法描述消失；本文设计主张限于共享形态参照与历史条件数量建模。
