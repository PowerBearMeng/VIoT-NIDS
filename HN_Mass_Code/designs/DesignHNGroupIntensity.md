# HN群体强度小实验（2026-10-12）

## 猜想

1. 消息平均和有限采样削弱了真实数量；保留群体质量能补充Mirai/SYN的区分信息。
2. 对有归属的行为通道建模，可减少把一个节点的全部异常赋给所有Flow的污染。
3. 群体识别改善不保证同一行为群体内部的正常/攻击Flow可分，必须分别验证。

保留有效1秒HN门控＋对比checkpoint，不续训、不更新其encoder或评分。
本轮训练的是两个小型正常群体预测器，属于模块诊断，不声称是新的端到端HN。
不使用R1/R2的UOT、容量求解或历史质量更新。

## 分组及观测

沿用原正常预训练测量encoder及16个行为锚点，复用已保存的behavior_anchor。
锚点不解释为视频/控制业务角色。分组为(匿名IP节点,发送/接收方向,行为通道,秒)。
端口只用于原Flow聚合及图索引；本群体计数跨端口累计，不输入IP/端口数值。

每个节点方向每秒统计16个通道的Flow数、包数、字节数，共48维，全部实际Flow
参与，无邻居采样、无异常阈值筛选。两个模型观测/预测对象分别为：

- Mean：每通道三项总量除以节点方向总Flow数，保留组成与平均标记。
- Mass：每通道原始三项总量，保留重复数量与总活动。

两者用正常数据拟合log1p和Robust尺度。空白秒为真实零观测；匿名节点首次出现
之前为padding，不更新GRU。每份capture独立重置，历史只读t-16至t-1。

## 正常预测模型

48维历史→一层GRU(hidden64)。历史状态64＋行为通道one-hot16＋方向one-hot2
→MLP(82,64,8)，预测8个正常活动状态的混合权重。
各状态为按通道三维的对角Gaussian，均值/尺度仅由正常数据初始化和学习。
状态均值限制在正常观测范围内；测试冻结状态，历史不能创造更高强度新状态。
这是变换空间的连续密度近似，不称为精确离散计数概率。

正常训练目标为p(该类数量/标记|该类出现,过去历史,方向,行为通道)。只对出现的
行为通道学习幅度；全量实际零活动仍进入历史。此实验不建模该类是否出现的概率，
避免仅用稀有性惩罚稀疏正常控制通信。每项密度包含Gaussian常数。

全量正常数据参与预处理与训练，无验证集、攻击调参或checkpoint选择。
两个模型各20轮；seed42、batch256、Adam1e-3、梯度裁剪5，保存最后完整epoch。
每轮完整覆盖所有正常活动-行为对，再补采样到至少100步；补采样不改变数量。

## 评分与预声明比较

每个活动-行为对的三维平均NLL为强度分数。每条Flow查询发送端所属行为通道，
不把整个节点48维共同异常分数赋给所有类型。接收端分数只作诊断，主融合不用max。
同一节点同一行为同一秒的Flow仍得到相同强度分数，尚未解决群体内部归因。

分别报告：旧HN、Mean、Mass、HN＋Mean、HN＋Mass。
融合仅为诊断，按全量正常Flow的Q50/Q95做不截断仿射对齐后相加，系数固定为1。
没有新增门控或依据攻击结果选择分支/权重；原HN权重保持不变。

固定测试Mirai、SYN camera-udp、LRDoS Stealth camera-udp、OS Scan camera-udp。
使用旧1秒缓存/分数，核对row_id、时间、包量、字节量及标签对齐；需要时提取一次。
标签只在冻结后用于AUROC、average precision、插值EER及误报分析。

分别报告活动-行为对的群体指标和逐Flow指标。群体标签为含任一攻击Flow即攻击相关，
这不表示其中每条Flow都攻击。重点比较：同一发送行为群体内的正常/攻击Flow、
不同群体正常Flow、RTCP、单包60字节及持续阶段。记录接收端复制污染作为诊断。

必要核对使用真实数据：数量/包/字节守恒、重复量Mean不变/Mass改变、历史因果性、
身份置换不改变结果、输入不读攻击标签、checkpoint不变及有限分数。不运行smoke
test，不生成批量SHA256。不因结果差而追加训练或更换融合规则。

输出：outputs/hn_group_intensity_pilot_20261012。
命令：.venv_v7/bin/python -u -m viot_nids_graph_pilot.group_intensity

## 本轮结果与设计边界

四份预声明捕获共1,934,767条Flow，两个预测器分别使用全部12,518条正常Flow
形成的19,109个正常活动-行为对训练。原HN未更新；本轮在CPU上完成。

四场景宏平均：原HN为AUROC 0.9332、插值EER 10.92%；HN＋Mass为
0.9903、2.62%；HN＋Mean为0.8693、18.01%。完整量的收益明显，单独Mass
为0.9919、1.73%，表明诊断用的固定相加在部分场景仍会损失强度支路的排序能力。

各模型各捕获自身最近经验EER点下，RTCP正常误报由63/1959降至26/1959。
混合发送行为群体中的正常Flow误报由116/286升至131/286，群体内部归因没有解决。
冻结Mass模型后去掉历史，Mirai AUROC由0.991738变为0.991731；当前主要证据
支持恢复群体数量，不能将收益归于历史GRU或视频状态协同。

四场景、单种子结果不代替全22场景验证。详细结果和误报口径见
outputs/hn_group_intensity_pilot_20261012/CONCLUSIONS.md。
